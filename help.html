Timer App Help

A quick reference for running the timer during a meeting. For the full walkthrough, see the printable user guide.

The basics

Pick a preset (or select a speaker from the Speaker List, which loads their own preset), then click Start. The big colour panel changes automatically as the speaker's time passes:

ColourMeaning
GreyNot yet at the minimum time
GreenWithin the target time
AmberGetting close to the limit
RedOver the limit
Flashing redWell over — wrap up now

Stop stops the stopwatch (and records the time against the selected speaker, if any). Reset stops and zeroes it.

One Minute is a special case: it stays neutral (grey) until exactly one minute, then jumps straight to solid red — there's no green/amber phase.

Manual clears any preset so the stopwatch just runs with no automatic colour changes — use the Green/Amber/Red/Clear buttons yourself instead.

Speaker List

Click Speaker List to open the editable list. Each row has a name, an optional preset (which fills in the four times for you), and the four times themselves in mm:ss — edit them directly if a speaker needs a custom timing. Save & Return to Timer saves the list and takes you back. The list and each speaker's actual time are stored in your browser, not on a server.

Add Table Topic (top row of the timer page) is a shortcut for impromptu speakers: it asks for a name, adds them to the list with the Table Topics preset already applied, and selects them ready to go.

Mini Player

The Configuration menu's Mini Player switches the control page to a compact layout — useful if you want to keep it open in a small window alongside everything else. Full View switches back. Your choice is remembered, including across a trip to the Speaker List and back.

Using it with OBS

Option A: an OBS Browser Source (recommended)

Use Copy Display Link and paste that URL into an OBS Browser Source. This works even though OBS's browser is a separate process from your own — the display and the control page keep in step by polling the server about once a second, and the display also runs the timer itself, so a brief network hiccup never freezes the colour.

Option B: a second window

Click Open Display to pop out the colour panel in its own window, then add it to your OBS scene as a Window Capture source. Control everything from the original tab — the two stay in sync instantly as long as they're in the same browser, but the window has to stay open and un-minimised for OBS to capture it.

Each control page gets its own random room (visible as ?room=... in the address bar), so several people can run the timer at the same time from the same site without interfering with each other — just make sure the display link you use matches the control page you're running.

Using a phone or tablet as a display

Phone / Tablet Display in the Configuration menu shows a QR code. Scan it with the other device's camera and it opens a full-screen colour panel that mirrors this timer — useful as a timekeeper's repeater, or propped up facing the speaker.

Once you press Start, the device is handed the whole schedule, not just the current colour. From then on it counts the speech on its own: if it briefly drops off the network it keeps showing the right colour and the little clock keeps turning, and it re-syncs automatically when the connection comes back. Stop and Reset still come from this page.

Two things to know:

  • Both devices must be able to reach the same address. In practice that means the same Wi‑Fi, with the timer opened from the computer's network address (something like http://192.168.1.20:PORT/) rather than localhost. The QR dialog warns you if the address won't work from another device.
  • The display asks the device to keep its screen awake, but a phone can overrule that — turn off auto‑lock, or set a long screen timeout, for a long session. Tapping the panel puts it into fullscreen.

Using a physical TimerCube

If you have a physical TimerCube (or Toast Timer) device, the Configuration menu can drive its light in step with the on‑screen panel. This needs Chrome or Edge on a desktop — the menu items stay hidden in browsers without Web Bluetooth / Web Serial.

Choose Connect Cube (Bluetooth) or Connect Cube (USB) and pick the device from the browser's prompt. Once connected, the cube follows every colour change and the Start / Stop / Reset buttons; connecting part way through brings it straight to the current colour. Disconnect Cube — or unplugging it, or leaving Bluetooth range — stops it.

The cube is used as a light only: this page stays in charge of the timing, so the cube's own buttons and presets are bypassed while it's connected.
